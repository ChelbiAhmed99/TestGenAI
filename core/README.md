# Core AI Generation Engine

This directory contains the Python codebase for the AI-driven test generator engine.

## Purpose
- Ingestion of requirements (Jira tickets, text files, PDF documents).
- Querying LLM (e.g., Gemini) with QA-specific prompts.
- Generating Gherkin scenarios (Given/When/Then).
- Generating automated Playwright TypeScript test scripts following the Page Object Model (POM) design pattern.
